Gmail 帳號 + App Password
Google OAuth Client ID

3. DEBUG = True（settings.py 第 18 行）

🟠 HIGH — 優先處理
5. ALLOWED_HOSTS = ['*']（第 20 行）
允許任何 Host header，容易被用來做 Host Header Injection 攻擊。

6. SESSION_COOKIE_SECURE = False（settings.py）
Session cookie 不加密傳輸，HTTP 下可被中間人攔截。

7. X-Forwarded-For IP 未驗證（users/views.py 第 38-43 行）
使用者可以偽造 IP，影響所有依賴 IP 的安全邏輯（登入記錄、封鎖等）。

🟡 MEDIUM — 計劃性修復
8. 所有認證端點沒有 Rate Limiting
以下端點可被暴力破解：

POST /api/users/login/
POST /api/users/register/
POST /api/users/password-reset/
POST /api/users/password-reset/confirm/
建議在 DRF 設定加入 DEFAULT_THROTTLE_CLASSES。

9. Serializer 用 fields = '__all__'（flows/serializers.py）
TaskSerializer 等暴露所有欄位，包含不應該給前端的內部欄位。改用明確的 fields = [...] 清單。

10. Google Maps API Key 傳給前端（guides/views.py 第 117-127 行）
maps_api_key 直接 render 進 HTML，任何人都可以在頁面原始碼看到。

11. Email 驗證 token 以明文存資料庫（users/views.py 第 484-487 行）
若資料庫洩露，所有驗證 token 直接可用。建議存 hash。

chatbot/views.py（多處 [DEBUG] print）
