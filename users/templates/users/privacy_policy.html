{% trans "隱私權政策" %}

{% trans "最後更新日期" %}：2026 年 7 月 21 日

{% blocktrans trimmed %}ReadyTo Taiwan（以下稱「本服務」）協助國際學生準備來台就學所需的各項流程。我們重視使用者的隱私，本政策說明我們會蒐集哪些資料、如何使用，以及使用者擁有哪些權利。{% endblocktrans %}

{% trans "一、我們蒐集的資訊" %}

  • {% blocktrans trimmed %}帳號資訊：電子郵件、姓名、密碼（以雜湊方式儲存，我們不會看到明文密碼）。{% endblocktrans %}
  • {% blocktrans trimmed %}個人資料頁：國籍、地區、就讀學校、系所、身份別（僑生／外籍生／港澳生）、入學狀態、預計抵台日期、是否持有台灣身分證、大頭貼照片、偏好語言。{% endblocktrans %}
  • {% blocktrans trimmed %}Google 登入：若使用 Google 帳號登入，我們會取得 Google 提供的姓名與電子郵件，用於建立或核對帳號。{% endblocktrans %}
  • {% blocktrans trimmed %}AI 聊天機器人：你與聊天機器人的對話內容，以及上傳給機器人的附件檔案（用於提供回覆）。{% endblocktrans %}
  • {% blocktrans trimmed %}登入紀錄：登入時間、IP 位址、裝置／瀏覽器資訊，用於帳號安全與異常登入偵測。{% endblocktrans %}
  • {% blocktrans trimmed %}學長姐分享區內容：你主動發佈的分享文字，會附上你的學校與系所（自動帶入，非額外蒐集）。{% endblocktrans %}

{% trans "二、我們如何使用這些資訊" %}

  • {% blocktrans trimmed %}提供並維護本服務的核心功能（任務流程、資訊中心、AI 助手、學長姐分享）。{% endblocktrans %}
  • {% blocktrans trimmed %}依你的國籍、身份別、入學狀態，客製化你需要完成的申請流程與提醒。{% endblocktrans %}
  • {% blocktrans trimmed %}保護帳號安全（例如偵測異常登入、驗證信箱、密碼重設）。{% endblocktrans %}
  • {% blocktrans trimmed %}改善服務品質與修復問題。{% endblocktrans %}

{% blocktrans trimmed %}我們不會將你的個人資料用於與上述目的無關的行銷用途，也不會出售你的個人資料。{% endblocktrans %}

{% trans "三、資訊如何與第三方共享" %}

{% blocktrans trimmed %}為了提供服務，部分資料會透過以下第三方服務商處理，僅限於實現對應功能所需：{% endblocktrans %}

  • {% blocktrans trimmed %}Supabase：資料庫與檔案（大頭貼、聊天附件）儲存服務商。{% endblocktrans %}
  • {% blocktrans trimmed %}OpenAI：處理你與 AI 聊天機器人的對話內容及上傳附件，以產生回覆。{% endblocktrans %}
  • {% blocktrans trimmed %}Google：提供帳號登入（OAuth）與地圖功能。{% endblocktrans %}
  • {% blocktrans trimmed %}Gmail：寄送帳號驗證信、密碼重設信等系統通知信件。{% endblocktrans %}

{% blocktrans trimmed %}我們不會將你的個人資料出售或出租給第三方作行銷用途。{% endblocktrans %}

{% trans "四、Cookie 的使用" %}

{% blocktrans trimmed %}本服務使用必要的 session cookie 來維持你的登入狀態，僅用於服務運作本身，不用於廣告追蹤。{% endblocktrans %}

{% trans "五、資料保存與刪除" %}

{% blocktrans trimmed %}我們會在你使用本服務期間保存你的帳號與個人資料。你可以隨時在帳號設定中申請刪除帳號，我們會依刪除請求移除你的個人資料，法規要求須保留之紀錄除外。{% endblocktrans %}

{% trans "六、資料安全" %}

{% blocktrans trimmed %}我們採取合理的技術措施保護你的資料，包括傳輸加密（HTTPS）、密碼雜湊儲存等。但沒有任何網路傳輸或儲存方式能保證百分之百安全，若發生資料外洩事件，我們會依法通知受影響的使用者。{% endblocktrans %}

{% trans "七、你的權利" %}

{% blocktrans trimmed %}你有權查詢、更正、刪除你的個人資料，或要求我們說明資料使用情形。如需行使上述權利，請透過下方聯絡方式與我們聯繫。{% endblocktrans %}

{% blocktrans trimmed %}我們可能不時更新本政策，重大變更會於本頁面公告，並更新上方「最後更新日期」。{% endblocktrans %}
