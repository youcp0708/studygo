{# ── 常見問題 ── #}
{% trans "常見問題" %}

{% trans "您想了解的都在這" %}

{% trans "申請台灣大學需要準備哪些文件？" %}›
{% trans "一般需要準備：護照、學歷證明（高中/大學畢業證書）、成績單、語言能力證明（中文或英文）、財力證明、健康檢查報告、推薦信（部分學校要求）、學習計畫書（研究所）。各校要求略有不同，請以各校招生簡章為準。" %}
{% trans "不會中文可以來台灣留學嗎？" %}›
{% trans "可以！台灣許多大學提供英文授課的學士班與研究所課程。若就讀中文授課課程，通常入學前需具備一定中文程度（如 TOCFL B1 以上），或在僑先部完成一年預科中文課程。" %}
{% trans "留學台灣的費用大約多少？" %}›
{% trans "學費依學校與科系不同，公立大學學士班約每學期 NT$20,000–50,000，研究所約 NT$25,000–60,000。生活費（住宿、餐飲、交通）約每月 NT$10,000–20,000。加上獎學金補助，台灣留學費用相對親民。" %}
{% trans "學生簽證如何辦理？" %}›
{% trans "收到台灣學校入學許可後，持入學許可函至所在地台灣駐外機構申請學生居留簽證（Resident Visa）。備妥護照、入學許可、財力證明、健康檢查等文件即可申請。" %}
{% trans "可以邊讀書邊打工嗎？" %}›
{% trans "可以，但需申請工作許可。持有效居留證（ARC）的外籍學生，入學後可向學校申請工讀許可，每週工時上限為 20 小時。寒暑假期間可申請全時工作。" %}
{% trans "全民健保什麼時候可以加入？" %}›
{% trans "持有效居留證（ARC），在台灣合法居留滿 6 個月後可強制加入全民健保。若有效工作許可可提前加保。加保後門診費用大幅降低。" %}
{% trans "申請流程需要多久時間？" %}›
{% trans "從開始申請到正式入學，通常需要 3–8 個月。建議提早準備：確認申請資格（6–12 個月前）、準備文件（4–6 個月前）、提交申請（3–4 個月前）、等待錄取（1–2 個月）、辦理簽證（1–2 個月）。" %}
