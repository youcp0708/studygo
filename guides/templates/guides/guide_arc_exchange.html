❓ {% trans "常見問題" %}
{% trans "港澳生的居留證跟一般外籍生的 ARC 一樣嗎？" %} ▼
{% trans "功能上相同，但法源不同。" %}
• {% trans "一般外籍生辦理「" %}{% trans "外僑居留證（ARC）" %}{% trans "」，依據《入出國及移民法》。" %}
• {% trans "以港澳身份入台的港澳生辦理「" %}{% trans "港澳居民居留證" %}{% trans "」，依據《香港澳門關係條例》。" %}
{% trans "兩者在台均可用於身份核驗、健保加保及銀行開戶等日常事務。" %}
{% trans "在台期間可以打工嗎？" %} ▼
{% trans "港澳生持居留證可申請工讀許可（每週不超過 20 小時）。需向學校取得工讀同意書後，至勞動部辦理工作許可。在校內工讀（如圖書館、系辦助理）通常只需學校同意，手續較簡便。未取得合法工作許可的工作行為依法屬違規，請務必事先申請。" %}
{% trans "居留證到期後怎麼辦？" %} ▼
{% trans "居留證通常每年更新一次，到期前" %} {% trans "30 天內" %} {% trans "即可申請延期。延期所需文件與初次申請類似（在學證明書、居留證正本、照片等），無需再繳健康檢查費。延期規費 NT$500。建議提早辦理以避免逾期。" %}
{% trans "港澳生可以加入全民健保嗎？" %} ▼
{% trans "可以。取得居留證後，透過學校衛生保健組辦理加保即可。保費依年度費率由學校代扣，學生費率比一般標準低。加保後就醫診所門診費用約 NT$150，享有與台灣學生相同的健保保障。" %}
{% trans "暑假返港澳超過 2 個月，健保怎麼處理？" %} ▼
{% trans "離台超過 2 個月前，可至學校衛保組辦理「" %}{% trans "出國停保" %}{% trans "」，停保期間不扣繳保費。回台後記得辦理「" %}{% trans "復保" %}{% trans "」以恢復保障。停保不影響居留證效期，但停保期間在台就醫無健保保障。" %}
{% trans "學校 OIA 會幫我辦居留證嗎？" %} ▼
{% trans "大多數學校會在開學初舉辦團體辦理場次，OIA 統一帶隊至移民署。建議迎新報到後立即前往 OIA 確認是否有統一辦理安排，以便提早準備所需文件，節省自行前往的時間。" %}
