❓ {% trans "常見問題" %}
{% trans "我是台灣的僑生（台灣護照）的僑生也需要辦居留證嗎？" %} ▼
{% trans "不需要。持中華民國籍由僑居地（台灣護照）入台的僑生，具有完整公民身份，無需辦理居留證。" %} {% trans "本頁服務適用於持外國護照入台就讀的僑生（海外永久居民等）。" %}
{% trans "健康檢查可以在抵台後才做嗎？" %} ▼
{% trans "可以。可於抵台後參加校內體檢（約 NT$780），或至學校指定醫院完成。注意檢查報告出爐需數天，請盡早安排以避免超過 30 天辦理期限。建議抵台後隔天即至國際事務處詢問體檢安排。" %}
{% trans "居留證辦理期間可以在台灣合法居留嗎？" %} ▼
{% trans "可以。申請提交後至居留證核發前，持入境章及申請收據即可作為合法居留證明。" %} {% trans "建議隨身攜帶此兩份文件，以備需要時出示。" %}
{% trans "可以在不同縣市的移民署辦事處辦理嗎？" %} ▼
{% trans "可以。全台各縣市均設有移民署服務站，選擇距離學校最近的辦事處即可。但建議選擇學校所在縣市的辦事處，方便日後延期和處理相關事務。" %}
{% trans "畢業後若要繼續留台，居留資格如何處理？" %} ▼
{% trans "在學期間以「就讀」為居留事由。畢業後如需繼續留台（例如找工作），需在畢業後 30 天內申請變更居留事由為「工作」或「其他」，或在找到合法工作並取得工作許可後辦理變更為「工作」居留事由。建議畢業前盡早規劃，避免居留證失效。" %}
