❓ {% trans "常見問題" %}
{% trans "我是外籍生（非僑生），可以透過海聯會申請嗎？" %} ▼
{% trans "不可以。海聯會管道僅適用於具僑生身份的申請者。外籍生（持外國國籍但不符僑生認定）須直接向各大學的國際招生辦公室申請，各校招生時程與文件要求請見各校官網。" %}
{% trans "僑生與外籍生有什麼不同？" %} ▼
{% trans "「僑生」是指具有中華民國國籍或華裔血統、長期居住海外並在當地接受教育者，依教育部規定認定，可享僑生獎學金及僑先部等特別管道。「外籍生」則是持非中華民國國籍護照入學者，通常透過各校獨立招生管道申請，可申請教育部臺灣獎學金。兩者身份認定不同，適用的招生管道與優惠也不同。" %}
{% trans "可以同時申請多所學校嗎？" %} ▼
{% trans "海聯會管道可填寫多個志願（學校 + 系所），系統依志願序分發，通常一個申請可含多個志願。外籍生透過各校獨立申請時，只要在截止期限前分別向各校提交申請即可，但需留意各校的申請費及文件要求可能不同。" %}
{% trans "中文不夠好，可以申請中文授課的系所嗎？" %} ▼
{% trans "各系所對中文能力要求不同。部分系所設有最低中文檢定門檻（如 TOCFL B1 以上），部分則接受入學後修讀中文語言課程作為補強。建議查閱目標系所的最新招生簡章確認，或聯繫學校國際事務處詢問。若中文尚未達標，也可先考慮申請全英語授課的系所或語言先修課程。" %}
{% trans "申請獎學金需要另外申請嗎？" %} ▼
{% trans "教育部臺灣獎學金需在入學申請時或入學後另行提出申請，通常透過台灣駐外機構或直接向學校申請，名額有限，競爭較激烈。僑生獎學金部分由海聯會或學校自動審核，部分需額外填寫申請表。學校自設的入學獎助學金通常在錄取通知中會一併說明。" %}
{% trans "我已在台灣就讀，可以轉學嗎？" %} ▼
{% trans "可以，但需注意轉學申請通常有年級限制（多限大二、大三），且需提供原校成績單及放棄學籍證明。各校轉學招生時程不一，通常在每學年結束前後辦理，詳情請查閱目標校系的轉學考簡章。研究所學生轉所需依各所規定辦理。" %}
