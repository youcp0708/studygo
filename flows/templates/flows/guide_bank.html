🏦 {% trans "在台開設銀行帳戶" %}

在台留學期間，銀行帳戶是領取獎學金、支付租金與日常消費的基本工具。本頁整理開戶銀行選擇與流程說明。

🏦 {% trans "推薦銀行選擇" %}
📮 中華郵政（郵局）外籍生首選
全台門市最廣，外籍生開戶最友善，當日即可拿到存摺與提款卡，不像一般銀行需等 3–5 個工作天審核。
✅ 優點：當日領卡、未有 ARC 也可辦（持統一證號）、存款有政府保障
❌ 缺點：ATM 主要在郵局內，跨行提款每次 NT$5+，轉帳超額 NT$8–15；App 功能較基本
📌 多人同行請提前預約，避免等候過久
🕔 多數郵局營業至 17:00，部分郵局更晚（比銀行多 1.5 小時）
🏛 台灣銀行獎學金首選
政府機關及教育部獎學金通常匯入台灣銀行帳戶，若你有申請政府獎學金則必備。中壢市區有分行。
💳 玉山銀行
線上銀行介面完善，英文客服較佳，支援 Apple Pay / Google Pay。對外籍生相對友善。
🏢 國泰世華銀行
ATM 據點多，與多家電商合作，網路銀行功能完整，學生使用廣泛。
📋 {% trans "所需文件（郵局）" %}
🛂護照正本雙證件之一
🪪 居留證（ARC）正本 或 統一證號基資表（尚未領 ARC 者） 雙證件之一
🖊 木頭刻印章（英文姓名）— 原子章、橡皮章不可用 必備
💵現金 NT$100（不收刷卡）必備
📱台灣本人手機號碼（辦 Visa 卡時需要）視需求
🖊
木頭印章哪裡買？學校附近文具店均可刻製，告知老闆「要刻木頭章」並提供英文全名，費用約 NT$50–100，等候約 20 分鐘。建議事前刻好，開戶當天直接帶去。印章等同你的簽名，請與存摺分開保管。
🪪 {% trans "統一證號說明" %}
ℹ️
已領有居留證（ARC）者：居留證號即為統一證號，無須另行申請，直接帶 ARC 正本開戶即可。
⚠️
尚未取得居留證者（部分港澳生）：需另向停留地移民署服務站申請「統一證號基資表」，攜帶護照正本及影本（免貼照片）。此號碼終身固定，日後領到居留證後，ARC 號碼會與統一證號一致。
💳 {% trans "提款卡選擇建議" %}
💳
建議選擇有 VISA 功能的 Debit Card（扣帳卡）：可 ATM 提款，也能直接刷卡消費、網購。郵局提供 VISA + 悠遊卡 或 VISA + 一卡通 兩種組合，可按需求選擇。請注意部分台灣商家不接受 VISA Debit，付款前請確認。
💡 {% trans "注意事項" %}
📱
建議先辦好 SIM 卡再去開戶：開通網路銀行與 Visa 卡需台灣手機號接收驗證碼，先有門號才能當場一次搞定。
🕔
注意營業時間 + 預留足夠時間：一般銀行週一至週五 09:00–15:30，郵局多至 17:00。外籍生開戶流程通常需 1 小時以上，請勿太晚抵達，以免被請回。
📅
台灣日期格式：先寫月份、再寫日子 — 2 月 1 日 = 2025/2/1（與部分地區習慣相反），簽文件時請注意。
🏫
建議前往學校附近郵局：大學周邊郵局對僑外生開戶經驗豐富，審核較快，手續更熟練。
⚠️
ARC 到期後記得更新帳戶資料：ARC 換新後需至銀行更新證件資料，避免帳戶被凍結。
🚨 {% trans "重要警示" %}
🚫
絕對不要將帳戶借給他人：依台灣法規，出借存摺、提款卡、網銀密碼均屬違法，輕則被列為詐騙嫌疑人，重則承擔刑事責任。若發現帳戶遭盜用或存摺遺失，請立即通知銀行。
📊
不要短期內在多家銀行開戶：台灣每次開戶銀行均會「拉聯徵」（查信用報告）。短期內記錄過多，銀行可能主動來電詢問，甚至拒絕開戶（防人頭戶）。建議先開 1–2 家即可。
